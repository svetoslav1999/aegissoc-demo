# AEGIS·SOC — Demo pública

Recorrido visual de **AegisSOC**, plataforma defensiva de auditoría e inteligencia de superficie de ataque.

🔗 **Demo en vivo:** https://svetoslav1999.github.io/aegissoc-demo/

## ¿Qué es esto?

Demo **estática y 100% segura**: HTML/CSS/JS sin backend, sin motor de escaneo y sin datos reales. Las imágenes son **maquetas SVG** con datos ficticios.

- ❌ Sin código del producto ni módulos de escaneo
- ❌ Sin backend, integraciones ni claves
- ✅ Maquetas con datos ficticios

> ⚠️ AegisSOC es una herramienta **defensiva**: solo para sistemas propios o con autorización escrita.

## Funcionalidades que muestra esta demo

- 🔴 Grafo de ataque en tiempo real (Cytoscape.js, motor propio)
- 🔍 Analizador de amenazas URL — pipeline de 10 etapas (phishing, typosquatting, TLS, IOCs)
- 🌐 Inteligencia OSINT (Hunter.io + Censys, sin clave API para el analizador)
- 📡 Hallazgos en tiempo real vía WebSocket
- 🖥 Dashboard SOC con mapa de infraestructura mundial
- 🎯 Mapeo automático a MITRE ATT&CK
- 🔐 Control de acceso por rol (JWT)
